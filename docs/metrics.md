# Metrics

Baseline these before changing anything.

## Quality
- **Escaped defects:** defects found after release
- **Change failure rate:** releases that need a rollback or hotfix
- **Rework rate:** stories reopened or followed by a fix

## Flow
- **Lead time:** brief accepted to running in production
- **Cycle time:** story started to done
- **Throughput:** stories finished per week
- **Review wait time:** pull request opened to first human review

## Adoption
- Share of pull requests that are agent-assisted, and their defect rate compared with the rest

## Agent review
- **Acceptance rate:** findings that lead to a change
- **Noise rate:** findings rebutted or dismissed
- **Unique catches:** findings no other check found

## Process
- Rework on stories from workshop-designed features compared with the rest
